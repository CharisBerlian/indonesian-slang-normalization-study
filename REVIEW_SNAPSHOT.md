# Local review snapshot v2.0.0

This versioned snapshot contains the manuscript and supplement sources and PDF previews, the study's source templates, frozen protocol/resource hashes, aggregate reports and results, focused tests, and aggregate figures. It is a local review preparation. It is not a public release, a license grant, an anonymized submission, or a self-contained exact reproduction of the original private hosted run.

The exact payload allowlist, file sizes and SHA-256 hashes are in `MANIFEST.json`. No source/normalized review text, dictionary mapping, per-review IDs, labels, group assignments or predictions, token payloads, generated private notebooks, credentials, or fine-tuned weights are included. Synthetic strings in the unit-test fixtures are constructed examples, not source review records. `REPRODUCIBILITY.md` documents what can be run from this snapshot and what requires controlled external resources; `reports/resource_availability.md` states the unresolved dataset and code terms. The included IEEEtran class retains its original third-party notice and LPPL terms. The snapshot has not been assessed for venue anonymity or approved for external distribution.

The small fixture smoke tests need only the pinned SVM environment and run without private artifacts. The included aggregate plot can also be regenerated without row-level data. Full audit/training require reacquiring resources and checking terms. Exact original replay additionally requires the original selection and private model/prediction artifacts; the hosted transformer weight hashes were first recorded after the historical selection freeze. A separate clean-workspace path for a new pre-test freeze is documented, but was not exercised through a new full training run.
