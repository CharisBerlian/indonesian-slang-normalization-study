# Dictionary-Based Slang Normalization for Indonesian Sentiment Classification

This repository is a private research workspace for the study. It contains the manuscript and supplement sources and PDF previews, frozen protocol and source checksums, reproducible analysis scripts, synthetic tests, aggregate results, and figures. It was prepared from the separately audited `review_snapshot_v2` payload; `MANIFEST.json` records that original 63-file snapshot, and this repository adds only this README, `.gitignore` and `.gitattributes` to that payload.

The included snapshot and manuscript describe the local, non-public state at the time they were prepared. The study is now also hosted in a private GitHub repository; that does not make it public, establish reviewer access, or make the repository anonymous. Publication, sharing and any required anonymization remain separate decisions.

No raw or normalized reviews, dictionary data or mappings, row-level split IDs, labels or predictions, token payloads, private generated scripts, credentials, or model weights are included. Resource availability and licensing questions are documented in [reports/resource_availability.md](reports/resource_availability.md). The study's own code has no project-level license grant; the bundled IEEEtran class retains its original LPPL notice. Do not assume that the repository's existence grants permission to redistribute third-party resources or project code.

[REPRODUCIBILITY.md](REPRODUCIBILITY.md) describes the smoke tests, pinned local environments, research workflow, and limits of exact historical replay. Reproducing the original held-out analysis requires separately controlled inputs and private model artifacts. Fresh training and selection use a separate clean pre-test workspace and may not reproduce the original model bytes. The per-dataset held-out results and uncertainty are summarized in [reports/final_evaluation.md](reports/final_evaluation.md), with four-cell diagnostics in [reports/fixed_model_diagnostics.md](reports/fixed_model_diagnostics.md).
