\section*{Artifact Availability and Reproduction}
The local \texttt{review\_snapshot\_v2} includes manuscript sources, preview PDFs, code, and aggregate results; it excludes review-level inputs or predictions, dictionary mappings, weights, private payloads, and credentials. It is not public and grants no code license. \texttt{REPRODUCIBILITY.md} documents commands and tested limits. Exact replay requires private original artifacts; the full workflow was not rerun from the snapshot.

PRDECT-ID's source states CC BY 4.0; the IndoBERT card states MIT. The pinned IndoNLU license file says Apache 2.0 but its README displays an MIT badge; SmSA terms remain unresolved. No explicit Kamus Alay license was identified.
